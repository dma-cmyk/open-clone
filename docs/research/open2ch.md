## 1. URL 構造とデータ形式

### 1.1 ホスト（板サーバ）分散

板ごとにサブドメインが分かれる「2ch 型」構成。板名（ディレクトリ名）はホストと組で一意。

| ホスト例 | 用途例 |
|---|---|
| `hayabusa.open2ch.net` / `hayabusa2` / `hayabusa3` | なんでも実況J、ニュー速VIP、地震、携帯ゲー |
| `uni.open2ch.net` | ニュース速報+、国際情勢、ブラウザゲー |
| `awabi.open2ch.net` | 東アジアnews+、Download、議員・選挙 |
| `kohada.open2ch.net` | 生活全般、なんでも実況U、FF・ドラクエ |
| `toro.open2ch.net` | ネットゲーム、オカルト、スケート |
| `ikura.open2ch.net` | 食品業界、既婚女性、なんでもあり |
| `anago.open2ch.net` | ビジネスnews+、嫌儲系 |
| `engawa.open2ch.net` | ニュー速(嫌儲)、同人ゲーム、戦争・紛争 |
| `open.open2ch.net` | お絵かき板、テスト板(nohara)、おんJゲーム/アニメ部 |
| `ana.open2ch.net` | スマホアプリ、最悪 |

### 1.3 subject.txt

```
1794097184.dat<>【12球団総合】プロ野球雑談・議論 2026-27 Part55 (718)
1794104653.dat<>お前らいつ外出てんの？ (11)
```
- 文字コード: **Shift_JIS**（UTF-8 ではない）
- 1 行 = `<key>.dat<>` + スレタイ + ` (<レス数>)`
- レス数は >>1 を含む総数（dat 行数と一致: 718 行 = 718）
- 並び: 更新順（新しい書き込みが上）
- **150 行で固定**（livejupiter / news4vip / occult / sato の 4 板すべて 150 行＝件数上限。全スレの完全一覧ではない）
- スレ一覧ページ（`/<board>/`）は別ロジック。初期表示 10 スレ＋「スレッドをもっと見る」で 11〜100 スレ（atwiki）

### 1.4 dat

`/<board>/dat/<key>.dat`、Shift_JIS、1 レス 1 行、区切りは `<>`、**5 フィールド固定**。

| # | 内容 | 例 |
|---|---|---|
| 0 | 名前（＋トリップ） | `名無しさん＠おーぷん` |
| 1 | メール（sage 等。空が多い） | `` |
| 2 | 日付＋ID | `26/11/08(日) 09:19:44 ID:MOoI` |
| 3 | 本文（HTML 化済み。`<br>`、`>>n` は `&gt;&gt;`、`<a class="_ank ank" href=…>`） | ` プロ野球について…<br>…` |
| 4 | スレタイ（**>>1 のみ**、以降は空文字） | `【12球団総合】… Part55` |

- 本文は表示用 HTML がそのまま入る（AA 用の `<br>` 等）。生テキストを別途持つ設計が望ましい。
- `!jien` 発動後は ID が `dO.i2.L5` 形式（2 文字 + プロバイダ 1 文字 + `L<忍法帖レベル>`）に変わる。dat でもそのまま記録される。

### 1.5 RSS / Atom

HTML の `<link rel="alternate">` は `/<board>/index.rdf`（RSS）と `/<board>/atom.xml`。ただし今回の取得は 403（アク禁ページ）。**存在は確認、内容は未取得**。

### 1.6 板一覧 bbsmenu.html

2ch 専ブラ互換の `bbsmenu.html`（Shift_JIS、`<B>カテゴリ</B>` の下に `<A HREF=板URL>板名</A>`）。
カテゴリ 41 個: 人気 / 運営 / 地震 / be / ニュース / 世界情勢 / 案内 / 馴れ合い / AA / 社会 / 会社・職業 / 文化 / 学問・理系 / 学問・文系 / 家電製品 / 政治経済 / 食文化 / 生活 / ネタ雑談 / カテゴリ雑談 / 実況ch / 受験・学校 / 趣味 / スポーツ一般 / 球技 / 格闘技 / 旅行・外出 / テレビ等 / 芸能 / ギャンブル / ゲーム / 携帯型ゲーム / ネットゲーム / 漫画・小説等 / 音楽 / 心と身体 / ＰＣ等 / ネット関係 / 雑談系２ / 運営案内。

## 2. 画面構成と UI

### 2.1 全体構造（PC）

- 入口 `/` は「おーぷん２ちゃんねるへようこそ」1 枚 + `[ 入る ]` + **10 秒で自動遷移**（`<meta http-equiv="refresh" content="10;URL=…/menu/">`）。viewport は `initial-scale=0.5`。
- `/menu/` は **frameset**（`cols="103,*"`）: 左 103px が板一覧（`pc_menu.html`）、右がロビー（`pc_top.html`）。
- ロビー: ロゴ画像、検索窓（`find.open2ch.net`）、「■おーぷん2ちゃんねるって？」「■独自機能もあるよ！」「■専ブラから見るには？」「■削除人＆協力者募集中」「■拡散用バナー素材」「■お知らせ」「■警察関係者の方へ」の `<b class=sub>` 見出し＋`.inner` 本文。
- 板ページ・スレページは frameset の右枠内で遷移（`target=_parent` のリンクも混在）。

### 2.2 板ページ（`/<board>/`）

上から:
1. **バナー** 490×120（`image.open2ch.net`）＋「(´∀｀)まだまだバナー募集中」＋「バナー一覧」

   - 右上: 検索フォーム（`select name=t`＝スレタイ/全文検索/google/画像検索、`input size=10`）＋人気検索ワード
   - `h1`（`font-size:14pt`、text-shadow）: `板名`＋`<font size=2>＠おーぷん</font>`

## 3. 機能一覧と仕様

### 3.1 ID

| 項目 | 実測/仕様 |
|---|---|
| 形式 | **4 文字の英数字**（大小混在）例: `MOoI` `5SuS` `3EyW` `l0oJ` `1AHp` |
| 生成単位 | 板ごと・日ごと（日付が変わるとリセット）。「日付が変わってもレス数カウントは継続」と atwiki |
| 非表示 | 板単位で `???`（`newsplus`・`sato` で実測）。`!no_id` コマンド（おんJ・VIP・ブラウザゲー板では不可） |
| 自演防止 `!jien` | `ID:` が `dO.i2.L5` 形式＝「ID の最初の 2 文字」＋ `.` ＋「プロバイダ由来 1 文字」＋ `.` ＋ `L<忍法帖レベル>` |
| クリック | `?id=<ID>` でその ID のレスのみ抽出。jien 時は 2 文字単位でも絞れる |
| 実装示唆 | IP＋UA＋日付＋板 のハッシュ → base62/base64 4 文字。[推測]（生成式は非公開） |

### 3.2 トリップ

- 名前欄 `#キー` → 名前の後ろに `◆` ＋ **10 桁**（実測: `◆1xBvFkA3bc`）
- 実装（2ch 互換の標準方式。[推測] だが形式・桁数は 2ch 互換そのもの）:
  1. キーを 12 文字までに切る
  2. 先頭 2 文字を salt に（英数記号以外は `.`）
  3. DES `crypt(key, salt)` → 13 文字
  4. 3 文字目以降 10 バイトを Base64（`. / 0-9 A-Z a-z` 系）→ 先頭 10 文字
  5. `◆` を前置
- **12 桁版**は したらば/MegaBBS 系の実装（2ch 系は 10 桁）。本クローンは 10 桁で固定してよい。
- 仕様書には「解読可能なので他サービスのパスワード流用禁止」と明記（Wiki/FAQ も同旨）。
- 実装は自前で書く（DES crypt 相当。Node/Workers では `crypt` が無いため DES 実装 or WebCrypto では不可 → 純 JS 実装が必要）。

### 3.3 キャップ

- スレ主が `!cap` で付与: `安価 + 改行 + !cap + 文字列` → 対象の名前欄に `▲文字列`
- 解除は `!cap` のみ。権限は付与されない（表示のみ）。副主は `!cap` / `!set` を使用可
- 公式キャップ（運営発行）も存在（板ごとのスレ立て権限等）

### 3.13 忍法帖・履歴・専ブラ

- **忍法帖**: Cookie ベースの投稿数レベル。レベルで使える機能が変わる（バルス Lv3、タイマー Lv20 等）。おーぷぬ板ではレベルが上がらない。
- **履歴**: 書き込み/既読スレを 300 件まで（超過で古い順に削除）、72 時間以内の安価有無を表示。
- **ブクマ**: スレ名横の ☆（SP）。
- **統計**: 全板のレス数・ID 数・スレ数・グラフ（現在休止）。
- **専ブラ対応**: `bbsmenu.html` + `subject.txt` + `dat` + `read.cgi` の 2ch 互換一式。板一覧 URL は `https://menu.open2ch.net/bbsmenu.html`。
- **おーぷぬ**: 誰でも板を作れる（`r.open2ch.net`）。1 週間投稿が無い板は自動削除。

### 4.4 依存関係メモ（設計への示唆）

1. **ID とトリップは書き込み経路の最初に必要**（Bot 対策・通報・NG が全部これに依存）。
2. **NG は「クライアント保存」が現実的**（おーぷんも設定はブラウザ側）。サーバは「非表示フラグ」だけ持てばよい。
3. **リアルタイム更新**はおーぷんが Socket.IO 常時接続。Workers Free では Durable Objects の利用枠に注意 → SSE + ポーリングへの置換を検討。
4. **dat/subject.txt 互換**を最初から設計に入れると、既存専ブラ利用者の移住ハードルが下がる（`Shift_JIS` 出力は Workers で `TextEncoder` の Shift_JIS 非対応に注意 → 変換テーブル or 事前生成）。
5. **HTML はサーバレンダリング前提**（おーぷんは jQuery 1.7.2 + 素の HTML）。Next.js でも「初期 HTML に全レス」を守れば体験が揃う。

| CSS/JS | `read.v11.css`、`main.v8.css`、`kome.v73_*.js`、お絵かきエディタ、背景 GIF(data URI) | 見た目の**傾向**（緑系・細枠・95% 幅・メイリオ）のみ参考にし、コードは独自実装 |
| キャラクター | おんJマン、kapa、野獣先輩モード、ミク音声 | 移植しない。読み上げは自前 TTS / 汎用音声に置換 |
| 音声・画像 | 効果音（太鼓・マリオコイン）、キャラクターの音声、運営者の自画像 | 使わない。自前 or フリー素材（ライセンス明記） |
| 外部サービスの名称・ロゴ | imgur、YouTube、X/Twitter、ニコニコ、ツイキャス、PayPay、2mtmex、Google Analytics | 埋め込みは各社の規約・ブランドガイドラインに従う。ロゴ画像は直リンクしない |
| 文化コンテンツ | AA（アスキーアート）、コピペ、`!バルス`（天空の城ラピュタ）、漫画コマ（「アル」） | AA は作者の著作物。テンプレ集を同梱しない。パロディコマンドは名称変更 |
| データ | 既存サイトの投稿本文・dat・subject.txt の大量取得 | 転載しない（サイトは CC0 を宣言しているが、第三者の著作物が混入し得る） |
| 表示 | 「著作権フリー：おーぷん2chはまとめ自由」等の文言 | 自サイトのライセンス方針として独自に策定 |

**補足**: 要件は「外観・操作性・主要機能を可能な限り再現」だが、**画像・CSS・JS のコピーは不可**。再現対象は「情報設計・操作フロー・書式（レス行の並び、URL 形、コマンド記法）」に限定するのが安全。
